# 🧠 ML & DL Practice – Models from Scratch (NumPy-Based)

This repository is a personal learning space where I’m building **machine learning, deep learning, recommendation systems**, and **reinforcement learning models from scratch**, using only **Python and NumPy** (no ML libraries like scikit-learn, TensorFlow, or PyTorch).

---

## 🚀 Goals

* Strengthen mathematical understanding of ML/DL algorithms
* Implement everything from scratch using NumPy
* Avoid black-box libraries and build true intuition
* Expand gradually into advanced areas: deep learning, recommendation systems, and RL

---

## ✅ What’s Done So Far

* 🔹 **Linear Regression with One Variable**
  Gradient descent implementation using synthetic NumPy data.

* 🔹 **Linear Regression with Multiple Variables**
  Vectorized gradient descent and feature scaling from scratch.

* 🔹 **NumPy Practice**
  Utility functions, matrix operations, broadcasting, and basic plotting (optional).
